# Package index

## Complete pipeline

End-to-end forest segmentation and metrics extraction.

- [`Forest_seg()`](https://rupppy.github.io/PiC/reference/Forest_seg.md)
  : Forest component segmentation, plot and tree metrics
- [`pic_analyze_cloud()`](https://rupppy.github.io/PiC/reference/pic_analyze_cloud.md)
  : Point cloud diagnostic analysis
- [`metrics_from_las()`](https://rupppy.github.io/PiC/reference/metrics_from_las.md)
  : Calculate tree and plot metrics from a classified LAS file

## Segmentation components

Individual segmentation steps.

- [`Floseg()`](https://rupppy.github.io/PiC/reference/Floseg.md) :
  Forest floor segmentation with DTM validation
- [`SegOne()`](https://rupppy.github.io/PiC/reference/SegOne.md) :
  Single Tree Wood-Leaf Segmentation and Comprehensive Metrics
  Calculation
- [`Voxels`](https://rupppy.github.io/PiC/reference/Voxels.md) :
  Voxelize Point Cloud (Optimized)
